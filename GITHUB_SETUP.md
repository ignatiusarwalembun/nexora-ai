## Upload with Git

Create an empty GitHub repository first, then run these commands inside this project folder:

```bash
git init
git add .
git status
git commit -m "Initial release: Maba Business Phase 4"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/maba-business-ai-platform.git
git push -u origin main
```

Before committing, verify with `git status` that `.env`, runtime data, tokens, API keys, and other private files are not staged.
