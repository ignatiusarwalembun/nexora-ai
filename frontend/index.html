FAQ

Pertanyaan yang biasanya muncul sebelum bisnis mulai pakai AI.

Apakah website ini sudah memakai OpenAI API?+

Belum. Phase 2 masih fokus pada experience local. Integrasi API dan knowledge base asli akan masuk di fase berikutnya.

Apakah chatbot bisa disesuaikan dengan brand?+

Bisa. Nama, tone, bahasa, aturan jawaban, knowledge, dan workflow dapat dirancang sesuai kebutuhan bisnis.

Apakah bisa digunakan di banyak channel?+

Arsitekturnya disiapkan untuk website dan channel messaging seperti WhatsApp serta Telegram melalui backend integration.

Apakah dark mode dan bahasa disimpan?+

Ya. Pilihan tema dan bahasa disimpan di browser agar pengalaman tetap konsisten saat halaman dibuka kembali.
